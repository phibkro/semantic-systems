# Theory Packages

Theory packages contain abstract types, operations, effects, laws, invariants,
and observational guarantees.

Early packages:

- algebra and lawful equality;
- collections and maps;
- state machines and protocols;
- effects and handlers;
- actor semantics;
- transactional stores;
- event logs;
- orders, semilattices, and CRDTs.

They must not depend on a particular executable representation.
