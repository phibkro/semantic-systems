# Research Bibliography and Technology References

This bibliography emphasizes primary papers and official project
specifications. Inclusion means the source informs a pattern or technology
boundary; it does not imply wholesale adoption.

## Semantic foundations

- Paul Blain Levy, *Call-By-Push-Value: A Functional/Imperative Synthesis*.
  <https://link.springer.com/book/10.1007/978-94-007-0954-6>
- Edwin Brady, *Idris 2: Quantitative Type Theory in Practice*.
  <https://research-repository.st-andrews.ac.uk/handle/10023/23560>
- Gordon Plotkin and Matija Pretnar, *Handling Algebraic Effects*.
  <https://arxiv.org/abs/1312.1399>
- Daan Leijen, Koka publications on row-polymorphic effects and
  type-directed effect compilation.
  <https://www.microsoft.com/en-us/research/project/koka/publications/>

- Lean Language Reference and kernel overview.
  <https://lean-lang.org/doc/reference/latest/>
- PLT Redex, *Practical Semantics Engineering*.
  <https://docs.racket-lang.org/redex/>
- K Framework user manual and executable semantics overview.
  <https://kframework.org/docs/user_manual/>
- George Necula, *Proof-Carrying Code*.
  <https://doi.org/10.1145/263699.263712>
- Anna Zaks and Amir Pnueli, *Program Analysis for Compiler Validation*.
  <https://llvm.org/pubs/2008-11-PASTE-CompilerValidation.html>
- *Towards Proof Generating Compilers*.
  <https://www.sciencedirect.com/science/article/pii/S1571066105050048>
