# Core Specification

This directory will hold the normative core calculus independently of parser
or backend implementation.

Initial specification units:

- syntax and binding;
- value and computation judgments;
- quantitative usage algebra;
- effect rows and operations;
- one-shot handler semantics;
- erased propositions and equality;
- inductive and coinductive formation;
- operational semantics;
- metatheorem statements and proof status.

Every rule should link to the model entity or decision that motivates it.
